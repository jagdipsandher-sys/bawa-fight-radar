# Feedback

What people have asked for, collated from the `[BAWA FEEDBACK]` emails the
buttons on the radar page send.

`log.md` is appended to every Monday by a scheduled Claude session that reads
the inbox, strips the addresses, groups the requests and pushes the result here.
It is the record of what users actually want — read it before deciding what to
build next.

Nobody's email address goes in `log.md`. The repo is public, so requests are
recorded by first name only, or anonymously.
